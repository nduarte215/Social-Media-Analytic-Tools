**Python for Influencers: Social Media Analytics**

**Analyze your brand's performance while learning Python.**  
This beginner-friendly notebook is designed for creators, microinfluencers, and marketers who want to turn social media metrics into actionable insights using real data from their own platforms.

This project uses data from my personal brand, **Girl Gone Verde**, to teach the fundamentals of Python, data cleaning, and simple visualizations — all through the lens of influencer analytics.

---

**Project Goals**

- Empower content creators to understand data using Python
- Provide a real-world, hands-on tutorial using actual post analytics
- Build a foundation for future automation, dashboards, and AI-powered tools

---

**What You’ll Learn**

- How to load and explore social media data (CSV/Excel)
- How to clean and structure engagement metrics
- How to calculate performance indicators (like engagement rate)
- How to sort and visualize top-performing posts
